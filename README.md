# ⌨️ Shortcut Finder

A small Streamlit app that finds keyboard shortcuts for any computer or program, using Google's Gemini Flash model.

## Features
- Pick your computer (Windows, macOS, Linux, ChromeOS) and a program (Chrome, Word, Excel, VS Code, ...) or type your own.
- Optionally describe what you want to do ("take a screenshot") to get the most relevant shortcuts.
- Results are grouped by category, filterable, and downloadable as CSV.
- Results are cached for one hour so repeated searches are instant.

## Files
| File | Purpose |
|------|---------|
| `app.py` | The whole app (UI + Gemini call) |
| `requirements.txt` | Python packages to install |
| `README.md` | This guide |
| `.gitignore` | Keeps your secret key out of GitHub |
| `.streamlit/secrets.toml.example` | Template for your API key |

## Run it on your computer
1. Install Python 3.10 or newer.
2. Open a terminal in this folder and install the packages:
   ```
   pip install -r requirements.txt
   ```
3. Get a free API key at https://aistudio.google.com/apikey
4. Copy `.streamlit/secrets.toml.example` to `.streamlit/secrets.toml` and paste your key inside.
   (Or skip this and paste the key into the app's sidebar each time.)
5. Start the app:
   ```
   streamlit run app.py
   ```

## Deploy on Streamlit Community Cloud
1. Upload this folder to a GitHub repository (do **not** upload `secrets.toml`).
2. Go to https://share.streamlit.io and sign in with GitHub.
3. Click **Create app**, choose your repository, branch `main`, and main file `app.py`.
4. Open **Advanced settings** and paste this into **Secrets**:
   ```
   GEMINI_API_KEY = "your-real-key"
   ```
5. Click **Deploy**.

## Notes
- The default model is `gemini-3.8-flash`; if your key cannot use it, the app falls back to `gemini-3.5-flash`. Set `MODEL_NAME` in secrets to choose another one.
- Shortcuts are generated by AI. Verify important ones in the program's own help menu.# shortcut-_keys
